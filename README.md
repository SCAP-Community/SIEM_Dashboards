# Example SIEM Dashboards for SCAP results
Shared repository for SIEM dashboards such as Splunk and Elastic from SCAP scanners.   Currently these dashboards only work with the SCAP Compliance Checker, but could be adopted by other SCAP scanners, and the core data could be incorporated into the next version of SCAP standards.

These dashboards are just examples of what end users could create.  Users are recommended to create their own dashboards, and share with the community.   If you create your own dashboard, or expand on the dashboards already submitted, please post your updates here for others to benefit from.
