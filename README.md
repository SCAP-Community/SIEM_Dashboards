# Example SIEM Dashboards for SCAP Results

Example Splunk and Elastic dashboard integrations for normalized security compliance scan results. Current verified example events originate from Security Compliance Checker (SCC); other assessment producers can be supported after mapping their output to the documented event contract.

The Splunk app is a demonstration, not a certified production reporting system. See `splunk/niwc/INSTALL.md`, `splunk/niwc/CHANGELOG-0.2.1.md`, and `splunk/niwc/docs/` for deployment, field naming and limitations. Contributions to the sample dashboards are welcome.
